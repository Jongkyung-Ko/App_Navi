# 개인정보 처리 고지 (초안)

App Navi는 현재 위치 주변 아파트 실거래 시세를 보여주기 위해 **기기 위치 정보**를 사용합니다.

## 수집·이용 항목

| 항목 | 목적 | 보관 |
|------|------|------|
| 대략적/정확한 위치(위도·경도) | 지도 표시, 주소 변환, 시군구 실거래 조회 | 서버에 영구 저장하지 않음. 요청 처리·단기 캐시(좌표 기반 주소 캐시) 후 만료 |
| 변환된 주소·법정동코드 | 화면 표시 및 실거래 API 파라미터 | 앱 메모리/세션 동안 사용 |

## 제3자 제공

- **카카오 로컬 API**: 좌표 → 주소/법정동 변환
- **공공데이터포털(국토교통부)**: 시군구·계약월 단위 아파트 매매 실거래 조회

로그인, 회원 가입, 광고 ID 수집, 위치 이력의 장기 저장은 하지 않습니다.

## 권한

- Android: `ACCESS_COARSE_LOCATION`, `ACCESS_FINE_LOCATION`
- iOS: `NSLocationWhenInUseUsageDescription` (앱 사용 중 위치)

권한을 거부하면 현재 위치 기반 기능을 사용할 수 없습니다.
