# 데이터 안전성 작성 가이드 (App Navi)

Play Console → 앱 콘텐츠 → 데이터 안전성

## 개요 질문

| 질문 | 답 |
|------|----|
| 사용자 데이터를 수집/공유하나요? | 예 |
| 수집한 데이터를 암호화하여 전송하나요? | 예 (HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 위치는 기기 권한으로 제어. 서버에 계정 데이터 장기 보관 없음 → 정책에 맞게 “삭제 요청 해당 없음/권한 철회”로 답변 |

## 수집하는 데이터

### 위치
- **대략적인 위치**: 예 (수집)
- **정확한 위치**: 예 (수집)
- 목적: **앱 기능** (주변 시세 표시)
- 필수 여부: 핵심 기능에 필요 (거부 시 위치 기반 기능 제한)
- 임시 처리: 가능하면 “일시적 처리”에 가깝게 표시 (장기간 프로필 축적 안 함)
- 제3자와 공유: 지도/서버 처리 범위에 맞게 설정  
  - 광고 판매 목적 공유: 아니요  
  - 기능 제공을 위한 처리(지도 SDK/서버): 해당 시 “공유/처리” 옵션을 화면 문구에 맞게 선택

### 기타
- 개인 식별 정보(이름/이메일 로그인): 앱에 로그인 없으면 **수집 안 함**
- 금융/건강/사진 등: **수집 안 함**
