# Play Console에 붙여넣을 문구

## 앱 이름
App Navi

## 짧은 설명 (80자 이내)
내 위치 주변 아파트 매매·전세·평단가 시세를 지도로 확인하세요.

## 자세한 설명
App Navi는 현재 위치 또는 지도에서 선택한 지점을 기준으로 주변 아파트 실매·전세 시세를 보여주는 앱입니다.

주요 기능
• 내 위치 주변 단지 시세 조회
• 지도에서 시세 / 평단가 모드 전환
• 평단가 히트맵으로 지역 시세 한눈에 확인
• 맵 전체보기와 텍스트 카드로 Top 단지 요약
• 면적(평형) 필터로 원하는 평형대만 비교
• 나레이션으로 Top 단지 시세 듣기 (선택)

사용 방법
1. 위치 권한을 허용합니다.
2. 홈 지도에서 주변 시세를 확인합니다.
3. 필요하면 지도를 길게 눌러 다른 지점을 조사합니다.
4. 시세/평단가 토글과 면적 칩으로 원하는 기준으로 봅니다.

참고
• 시세는 공공 실거래 데이터를 바탕으로 집계되며, 실제 거래가와 다를 수 있습니다.
• 원활한 이용을 위해 인터넷 연결과 위치 권한이 필요합니다.

## 카테고리 추천
부동산 (없으면: 라이프스타일 / 도구)

## 태그/키워드 힌트 (설명문에 자연스럽게 포함됨)
아파트, 매매, 전세, 평단가, 시세, 부동산, 지도
